## What I Build

RTS is a reconstructable decision and execution framework for human + AI systems.

It records:

- context and assumptions
- authority and approval
- execution parameters
- outcomes and failures
- the point where a decision changed

The operating principle is:

```text
Security Gate
→ Cost / Consequence Gate
→ Explicit Single-Use Approval
→ Scoped Execution
→ Outcome Verification + Audit
```

Untrusted images, video, audio, documents, archives, prompts, manifests, filenames, metadata, URLs, and tool arguments are inspected before they can reach paid services or execution environments. Unknown input fails closed. Paid or externally mutating actions are never automatic fallbacks.

---

## 限界開発 / Limit Development

限界開発 is public, smartphone-first development under severe resource constraints.

It does not hide the awkward parts. Specifications, failures, assumptions, tests, cost boundaries, and handoffs remain visible so the development path can be reconstructed.

Normal work stays on the smallest available environment. External compute is used only as a manually approved emergency overflow path when the normal environment cannot finish the task.
