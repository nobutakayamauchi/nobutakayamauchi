# GitHub Profile Status

Status: ACTIVE / PROFILE / PUBLIC SURFACE

This repository is the public GitHub profile surface for Nobutaka Yamauchi and the RTS ecosystem.

It is a public positioning surface, not RTS core.

It is not RTS-AGE.

It is not a product repository.

It is not an operations log repository.

It is not a personal diary or private context store.

## Current Position

The profile README should remain concise, public-facing, and stable.

Its job is to explain:

- who the operator is
- what RTS is broadly about
- where the canonical RTS repository is
- how collaborators can understand the current public direction

Allowed by default:

- clarify public positioning
- update links to canonical public repositories
- improve concise explanation of RTS and current work
- add public-safe project pointers
- keep contact language simple and non-committal
- document profile maintenance boundaries

Prohibited by default:

- adding private context
- adding sensitive personal details
- adding internal operations logs
- adding business delivery workflows
- adding customer information
- adding secrets, tokens, or credentials
- overclaiming production readiness
- presenting experimental work as finished commercial infrastructure
- turning this repository into RTS core or a product repository

## Boundary

RTS defines the protocol and canonical public system material.

RTS-AGE may hold implementation gateway work.

Product repositories hold product-specific work.

This profile repository should only present the public operator surface and stable directions.

## Minimum Alive Definition

This repository is considered Minimum Alive when:

1. The public profile role is explicit.
2. The canonical RTS repository is discoverable.
3. Public positioning is concise and not overclaimed.
4. Sensitive or operational material is excluded.
5. Future edits preserve a stable public surface.

## Current Decision

Keep this repository.

Treat it as the public GitHub profile surface for the RTS ecosystem.

Do not use it as a working repository, product repository, private note repository, or operations log.
